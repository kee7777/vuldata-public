# Curating Commit Patches for Software Vulnerability Research and Learning
This project aims to collect commit patches for software vulnerability identification and learning. It consists of two thrusts:
1. (Thrust 1) Curating CVEs for Enhancing Learning of Software Security - curating commit patches from CVEs
2. (Thrust 2) Measuring Performance Gains with Small Scale Human Labeling in Software Vulnerability Detection - labeling commit patches from Open-Source projects
